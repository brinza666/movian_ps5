# Movian PS5 v0.7.0 — FFmpeg linked

Native ShadowMount title `PPSA99455`.

- Static FFmpeg 6.1.2: H.264, AAC, MP2, MP3, MPEG-1/2, file://, MP4/MOV/MKV/TS/AVI
- MPEG-1 still uses pl_mpeg
- `eboot.bin` ~3.4 MiB
- Title `contentVersion` 01.000.007

**Honesty:** this binary **links** FFmpeg. Cross on an MP4/MKV will try
to play. That path has not been watched on this console yet. If it
fails, MPEG-1 `.mpg` still should.
