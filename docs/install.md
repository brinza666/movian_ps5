# Install

Movian is a **ShadowMountPlus title**, the same class of homebrew as
[VLC for PS5](https://github.com/ZiZc3/VLC). Title id `PPSA99455`.

There is **no Phase 0 GitHub Release zip yet**. Build from source
([BUILDING.md](BUILDING.md)) or wait for a tagged `contentVersion`.

Historical zips under the `shadowmount` and `pre-alpha` tags were
produced by the archived trees. Treat them as obsolete.

## Console prerequisites

- Firmware with a working jailbreak (this house: Relapse → kstuff → etaHEN)
- [ShadowMountPlus](https://github.com/drakmor/ShadowMountPlus)
- FTP (ftpsrv **2121** or etaHEN FTP)

You do **not** send `eboot.bin` to elfldr port 9021.

## Folder layout

```text
/data/homebrew/PPSA99455/
  eboot.bin
  sce_sys/param.json
  sce_sys/icon0.png
  sce_module/libc.prx          (generated by the kit)
  assets/fonts/…
```

Copy the whole folder. Restart ShadowMountPlus or wait for its scan
(~90 s). Launch **Movian** from the home screen.

Media does **not** belong inside that folder. See [usb.md](usb.md).

## First run

Color splash from the system, then the four-tab shell (Home, Videos,
BitTorrent, Plugins). Phase 0 has no playback. If the process exits
immediately, pull `/download0/movian-ps5.log` over FTP and capture klog
TCP 3232.
