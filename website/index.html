Movian for PlayStation 5

A native home-screen port of the Movian media center. Same product as M7 on PS3 and movian-go on the desktop; same packaging as VLC for PS5.

Latest test release — v53

Movian HEVC Test v53 adds an in-video control bar with seek previews, audio track selection, and a subtitle picker that lists embedded tracks. Subtitle rendering is pending. The test title is PPSA99456.

Playback, seeking, and picker navigation passed host tests. Console verification of v53 is pending. The package excludes sandbox-lift.

How it ships

Native title

Signed eboot.bin in /data/homebrew/PPSA99456, launched from the PS5 home screen via ShadowMountPlus.

Not a Go ELF

Stock Go freebsd/amd64 dies before main on this userland. movian-go remains the behaviour reference.

Not port 9021

Payloads are a different file. Do not send eboot.bin to elfldr.
