Movian for PlayStation 5

A native home-screen port of the Movian media center. Same product as M7 on PS3 and movian-go on the desktop; same packaging as VLC for PS5.

Status

The live tree is an honest DualSense shell: Home, Videos, BitTorrent, Plugins. Playback, torrents, and the plugin host are the next phases — they are not in this binary. Earlier GitHub trees over-claimed those features; that code is archived.

Get the source

git clone https://github.com/brinza666/movian_ps5.git
cd movian_ps5
# WSL2 Ubuntu 24.04
bash scripts/doctor.sh
bash app/build.sh

New contributors and AI sessions: read docs/NEW_SESSION.md.

How it ships

Native title

Signed eboot.bin in /data/homebrew/PPSA99455, launched from the PS5 home screen via ShadowMountPlus.

Not a Go ELF

Stock Go freebsd/amd64 dies before main on this userland. movian-go remains the behaviour reference.

Not port 9021

Payloads are a different file. Do not send eboot.bin to elfldr.
