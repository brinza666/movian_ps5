Build and install

git clone --branch test/native-playback https://github.com/brinza666/movian_ps5.git
cd movian_ps5
# WSL2 Ubuntu 24.04, public SDK and starter kit provisioned
# Set PS5_PAYLOAD_SDK, PS5_STARTER and PS5_HOST for your setup
bash scripts/doctor.sh
bash scripts/build-ffmpeg-ps5.sh
bash scripts/self-check.sh
bash app/build.sh

Close the test title, upload the complete build/app/PPSA99456 folder to /data/homebrew/PPSA99456 through the console FTP server, verify its files, then scan/mount through ShadowMountPlus and launch the icon. Persistent settings/plugins survive an app-folder replacement.

The isolated test title PPSA99456 and production title PPSA99455 have separate folders and profiles. Follow the README for requirements, mounting, host/console checks and remote-controller usage.

How it ships

Native title

Signed eboot.bin in /data/homebrew/PPSA99456, launched from the PS5 home screen via ShadowMountPlus.

Native C++20

FFmpeg and platform hardware decoding feed the native player. Desktop behavior is checked against the installed M7 build and retained evidence.

Home-screen launch

Use the complete signed title folder with ShadowMountPlus. Port 9021 is a separate payload-loader path; do not send eboot.bin there.
